# Northstar Bank — Account Management Demo

A responsive browser-based bank account management demo. It lets you create accounts, record deposits and withdrawals, transfer demo funds between accounts, and review recent activity.

## Run it

Open `index.html` in a modern browser. No build step or package installation is required.

## Features

- Multiple savings and current accounts
- Balance overview and monthly deposit/withdrawal totals
- Deposit, withdrawal, and account-to-account transfer flows
- Transaction validation and recent activity filtering
- Browser-local persistence using `localStorage`
- Reset control to restore the sample data
- Responsive layout for desktop and mobile

## Important

This is a front-end demonstration only. It does not connect to a bank, move real money, authenticate users, or provide secure financial storage. Data is kept in the current browser and should not be used for real banking or sensitive information.
